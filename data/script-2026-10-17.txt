Now the news. There's a lot of it today, so I'll group it by theme. The biggest theme is open models, which are having a moment.

Muse Spark Open is a multimodal open-weight model with 816 billion parameters, 42 billion of them active at a time, and a context window of one million tokens. It's built for coding and long, multi-step agent tasks. The detail that stood out is that it can run locally across two Apple M5 Ultra Mac Studios using MLX. That's a frontier-sized model on desk hardware.

Nvidia released Nemotron 3.5 Super VL, a multimodal reasoning model. It scored 26.5 on the Artificial Analysis Intelligence Index while using substantially fewer output tokens than its predecessor. Nvidia also introduced a smaller model called Nemotron 3.5 Bolt, plus near-lossless NVFP4 quantized weights. A Wall Street Journal headline groups Nvidia, Meta, and Apple together as unveiling new open models this week.

Microsoft shared how it trained MAI-Base-2. It's a 2.8 trillion parameter mixture-of-experts model with 80 billion active parameters. Microsoft says it beat every open-weight model in its held-out pre-training evaluations. The deep dive covers data strategy, compute efficiency, and infrastructure. Microsoft also plans to turn internally trained frontier models into enterprise offerings through Foundry. That last part matters if you're in the enterprise AI business, Zach, which you are.

DeepSeek launched V4.1 Flash 1017, and one headline says it beats Claude Opus 5 on some benchmarks. On the image side, Black Forest Labs released FLUX 3 Image Klein. Here's the number that ties it together. Vercel's gateway data says open-weight models now process 71.5 percent of tokens, though only about 23 percent of the dollars. For the researchers, there are three deep dives. The first is titled Neural Networks Are Already Clean. It argues that what looked like arbitrary packing of concepts in networks was mostly recursive generalization, which is less concerning. That means networks can be studied directly, and the outlook for interpretability may be better than we thought. The second, The Gradient Is a Covariance, shows that reinforcement learning and related methods changing only a small fraction of parameters doesn't mean the changes are simple. Small and sparse are different claims. The third, Mo' Turns, Mo' Problems, is a practical look at reinforcement learning for agents. The setup is simple, but agents spawning subagents, making parallel tool calls, and compacting long sessions all push the trajectories off-policy. A few related reads: one on why cost per task is the number to watch, one on code review after code gets cheap, and one on agents beating two accelerator chips in 24 hours.

Last, the IBM front. IBM published the first edition of its Open Source Security Signals report, for the third quarter of 2026. The core idea is that open source is the foundation of modern software because it works, and that its transparency is part of its security model. Code can be inspected, researchers can test it, and fixes benefit everyone who depends on it. But the same scale makes security more complex, since modern applications can rely on hundreds or thousands of components linked through deep dependency trees. IBM argues that counting vulnerabilities isn't enough. A critical vulnerability might pose little real exposure in a given environment. A lower-severity weakness can become serious when paired with another one. Compromised credentials or a permissive configuration can change the picture too. Finding the flaw is only the start. Teams still have to understand the risk, decide whether to act, find a usable fix, and get it to the software that needs it.
