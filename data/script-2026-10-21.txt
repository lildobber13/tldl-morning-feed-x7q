Why it matters: cheaper and faster models change what's practical to build. MiniMax released M3.1 Flash, which it says is a generational leap in agentic tasks, coding, computer use, and cybersecurity. Also on speed, Inception Labs introduced Mercury 3, a diffusion-based language model. It reportedly beat GPT-6 Luna and Claude Haiku 5.5 on multiple benchmarks while generating over 1,000 tokens per second.

Here's a different idea. Cloudflare introduced Clairic, which it calls an extraction model, a new class of System One style model. It pulls values directly from unstructured input, computes them, or predicts beyond them. The key point is that it doesn't generate tokens, so it can't produce a mistyped answer or hallucinate the way an LLM can. It can still be wrong, but it gives confidence scores so you know when to take a second look. For anyone processing messy documents, that's a very interesting trade.

Ethan Mollick looked at 30 months on the exponential, in charts. His point is that AI's gains are big enough that how we work with it has to change. Before, work was split between AI and humans. Now, IBM. Why it matters: it speaks directly to the cost story running through everything today. llm-d 1.0 was announced yesterday, a major milestone for the open source project that helps organizations deploy and scale large language model inference more efficiently. It was founded in 2025 by Red Hat, IBM, Google Cloud, CoreWeave, and NVIDIA, and it's now governed by the Cloud Native Computing Foundation.

The pitch is that running AI at scale can be as hard and expensive as building the models. Agentic workloads add stress, because agents constantly reuse huge amounts of context and can create unpredictable bursts of activity. Managing that context can cost more than generating the final output. So llm-d 1.0 aims to improve performance and throughput and give organizations more control over the economics of serving. Out of the box it offers hardware heterogeneity, prefix-cache and load-aware routing, and KV cache offloading, among other capabilities. That's a nice companion to the vLLM story from earlier.
